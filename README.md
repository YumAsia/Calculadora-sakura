# 🌸 Calculadora de Arroz · Yum Asia Sakura

> Calculadora interactiva de arroz y agua para la arrocera **Yum Asia Sakura** — optimizada para móvil.

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live-brightgreen?style=flat-square&logo=github)](https://TU-USUARIO.github.io/TU-REPOSITORIO/)

---

## ✨ Funciones

- 🍚 **Arroz Blanco** (redondo) — ratio `1 : 1.5`
- 🌾 **Arroz Integral** (brown rice) — ratio `1 : 2`
- Entrada en **tazas o gramos**
- Atajos de raciones rápidas: 1 / 2 / 3 / 4 personas
- Barra visual de proporción arroz : agua
- ⚠️ Aviso automático si superas el límite de 1.5L de la Sakura
- Consejos PRO adaptados a cada tipo de arroz

## 🚀 Cómo publicarlo en GitHub Pages (paso a paso)

### Paso 1 — Crear el repositorio

1. Ve a [github.com](https://github.com) e inicia sesión
2. Haz clic en **"New repository"** (botón verde arriba a la derecha)
3. Ponle un nombre, por ejemplo: `sakura-arroz`
4. Marca la opción **"Public"**
5. Haz clic en **"Create repository"**

---

### Paso 2 — Subir el archivo

Una vez creado el repositorio, verás una página vacía. Haz clic en **"uploading an existing file"**:

```
Tu repositorio está vacío.
Puedes crear un nuevo archivo o → uploading an existing file
```

Arrastra el archivo `index.html` a la zona de subida y haz clic en **"Commit changes"**.

---

### Paso 3 — Activar GitHub Pages

1. Ve a **Settings** (pestaña superior del repositorio)
2. En el menú izquierdo busca **"Pages"**
3. En **"Source"** selecciona:
   - Branch: `main`
   - Carpeta: `/ (root)`
4. Haz clic en **"Save"**

---

### Paso 4 — Obtener tu URL

Después de unos segundos (puede tardar 1-2 minutos), GitHub Pages te mostrará tu URL:

```
🎉 Your site is live at:
https://TU-USUARIO.github.io/sakura-arroz/
```

¡Ya puedes abrirla desde el móvil y guardarla como acceso directo!

---

## 📱 Guardar como acceso directo en el móvil

### iPhone (Safari)
1. Abre la URL en Safari
2. Toca el botón de compartir ↑
3. Selecciona **"Añadir a pantalla de inicio"**

### Android (Chrome)
1. Abre la URL en Chrome
2. Toca los tres puntos ⋮
3. Selecciona **"Añadir a pantalla de inicio"**
